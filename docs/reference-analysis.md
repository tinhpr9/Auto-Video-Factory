# Reference clip analysis

The supplied reference is used only to define pacing/layout characteristics, not to copy its characters or artwork.

Observed characteristics:

- ~57 seconds, 30 fps.
- Mostly static fantasy/xianxia illustrations with subtle movement.
- Cold cyan/white palette, snow/mist atmosphere.
- Narration-led pacing: one visual beat per spoken beat.
- Vietnamese subtitles centered in the lower portion of the frame with a dark outline.
- Minimal transitions; the storytelling and voice carry the video.

V1 therefore proves the reusable structure: story beats -> per-scene narration -> per-scene visuals -> timed subtitles -> subtle Ken Burns motion -> MP4.
